# Урод

Небольшая 2D-игра про школьника на питбайке. Работает в современных мобильных браузерах Android (Chrome) и iPhone/iPad (Safari), а также на компьютере. Используются только HTML, CSS, JavaScript и Canvas — без сборки, npm, библиотек и CDN.

## Файлы

- `index.html` — разметка и интерфейс.
- `style.css` — адаптивный интерфейс, включая безопасные зоны iPhone.
- `game.js` — игровой цикл, физика, отрисовка, управление и сохранения.

## Публикация на GitHub Pages

1. Создай новый репозиторий на GitHub.
2. Загрузи в корень репозитория все четыре файла: `index.html`, `style.css`, `game.js`, `README.md`.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/ (root)`, затем нажми **Save**.
6. Через минуту открой `https://ИМЯ_ПОЛЬЗОВАТЕЛЯ.github.io/ИМЯ_РЕПОЗИТОРИЯ/`.

## Как играть

- **ГАЗ** — удерживать для разгона.
- **ТОРМОЗ** — удерживать для замедления.
- **ПРЫЖОК** — перепрыгивать припаркованные Жигули.
- **ВИЛИ** — удерживать для бонусных очков; следи за отдельной шкалой угла: зелёная зона безопасна, жёлтая и оранжевая предупреждают, красная зона заканчивается падением на 80°.
- Собирай бутылки «ГАЗЯВА»: они дают очки и валюту для магазина.
- В магазине можно покупать и выбирать скины. Покупки, выбранный скин, рекорд и кошелёк сохраняются в `localStorage` браузера.
- Каждый новый забег получает новую случайную расстановку машин, бутылок и элементов посёлка. На максимуме спидометр показывает 50 км/ч; скорость дополнительно подчёркивается быстрым движением разметки, обочины и вращением колёс. Столкновение происходит при касании габаритов байка и автомобиля.

На компьютере: `←` тормоз, `→` газ, `↑`/`W` вили, `Пробел` прыжок.

## Совместимость с телефонами

Игра подстраивает размер игрового поля под экран, учитывает вырезы и системные панели через `safe-area-inset`, использует Pointer Events для сенсорных кнопок и поддерживает Web Audio с префиксом Safari. Для звука требуется первое нажатие пользователя — это ограничение мобильных браузеров. Рекомендуются актуальные версии Safari на iOS и Chrome на Android.
